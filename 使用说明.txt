LocalSend Chat v2.5.1 使用说明
========================================

一、这是什么
----------------------------------------
一个跑在 Windows 上的局域网聊天窗口，基于 LocalSend Protocol v2。
协议本身未改动，所以官方 LocalSend 手机客户端可以发现它、给它发消息
和文件，它也能给手机发送。全程只在局域网内，不经过服务器，不需要账号。


二、运行
----------------------------------------
1. 双击 LocalSendChat.exe 即可，不用安装，不用装 Python 或任何依赖。
   程序是 7-Zip 自解压绿色包，运行时会把内置运行时释放到临时目录。
2. 首次运行 Windows 防火墙会弹窗，请勾选「专用网络」再点允许。
   如果点错了或没弹窗，可在程序里点「修复防火墙权限 / 自动修复」。
3. 窗口可以自由拖动和调整大小。
4. 顶栏有「关于」按钮，可查看版本、端口与上游声明。
   双击顶栏的版本号八次、输入管理口令，可以修改面板名称。


三、和手机配对
----------------------------------------
1. 手机安装官方 LocalSend（https://localsend.org）。
2. 手机和电脑连到同一个 Wi-Fi。注意别连到访客网络，也别开 AP 隔离。
3. 在电脑上点「刷新设备」，等手机出现在设备列表里。
4. 如果一直刷不出来，点「添加设备」，手动填手机 IP。
   手机 IP 可在 LocalSend 的「设置 → 关于」或路由器客户端列表里查到。
   手动输入 IP 属于明确操作，即使该设备曾被屏蔽也一定能连上。
5. 顶栏的在线数字，永远等于左侧列表里能数出来的在线设备数量。


四、删除设备与屏蔽设备（v2.5.1 起分开）
----------------------------------------
在会话行上点鼠标右键，会看到两个不同的动作：

- 删除该设备：只是把这段对话移出列表，不会拉黑对方。
  弹窗里选「是」会连带清空聊天记录，选「否」只移出列表、记录保留。
  只要手机还在线，下次点「刷新设备」或对方发消息，它就会重新出现。
- 屏蔽该设备：写进持久化名单，刷新也不会再出现，适合邻居的设备
  经常误出现在列表里的情形。聊天记录会保留。

左下角有一行浅色的「已屏蔽 (N)」，点开能看到所有被屏蔽的设备，
可以逐个点「恢复」，也可以「一键全部恢复」。设置页里也有同一个入口。

注意：旧版本（v2.5.0）把「删除」做成了永久拉黑，名单写在
%APPDATA%\LocalSendChat\chat.db 的 hidden_peers 表里，不在 config.json 中。
如果从旧版升级后设备仍然不出现，请升级到 v2.5.1 后打开「已屏蔽 (N)」，
点「一键全部恢复」即可，不需要删除 config.json，也不会丢主题和别名。


五、发消息和发文件
----------------------------------------
- 选中设备后，在输入框打字，回车发送，Shift+回车换行。
- 点「＋ 发送文件」可选择一个或多个文件发送。
- 图片会在聊天里显示实时缩略图。
- 勾选多个设备后点「群发」，可一次发给多台设备。
- 右键菜单可「清空聊天记录」，记录只保存在本机。


六、链接分享
----------------------------------------
点「⤴ 链接分享」→「开启分享」，添加要分享的文件或填写一段文字，
再点「复制链接」。同一 Wi-Fi 下的手机用浏览器打开这个链接，
就能直接下载文件或一键复制文字，手机端不用装任何额外应用。
这一功能走 53319 端口，和 LocalSend 协议端口相互隔离。


七、配色与界面
----------------------------------------
「设置 → 选择配色」里有 6 套主题：
深空蓝、墨玉青、极光紫、暖砂棕、月白、樱雾粉。


八、数据放在哪里
----------------------------------------
聊天记录、配置、证书、日志都在：
    %APPDATA%\LocalSendChat\
其中聊天记录、已知设备、屏蔽名单都在 chat.db，主题和别名在 config.json。
如需换位置，设置环境变量 LSC_HOME 指向新目录即可。
启动失败时先看同目录的 startup.log。
卸载时删除 exe，再手动清理上面这个目录即可，不留注册表项。


九、端口
----------------------------------------
    53317  TCP/UDP   LocalSend v2 收发与组播发现（固定，不能改）
    53319  TCP       链接分享网页

如果手动配置防火墙，需要放行 TCP 与 UDP 的 53317，以及 TCP 的 53319。


十、连不上设备怎么排查
----------------------------------------
点程序里的「自动修复」，它会扫描本机网段、放行端口、重新宣告本机。
常见原因：
- 电脑防火墙拦了入站：放行 53317，或点「修复防火墙权限」。
- 路由器开了 AP 隔离 / 组播过滤：换普通 Wi-Fi，或用手机热点试。
- 对端端口不是 53317：用「添加设备」手动填 IP。
- 虚拟网卡干扰：临时禁用多余虚拟网卡再试。
程序里的状态页会显示组播加入、发包、收包、扫描命中等计数，可据此判断。


十一、已知限制
----------------------------------------
- 没有「对方正在输入」提示，也没有离线消息队列。
- 大文件速度受局域网带宽限制。
- 目前只有 Windows 版本。
